## Overview
This repository contains the data, R scripts and write-up for a study of the ESG premium (the yield difference between ESG-certified and conventional bonds) in corporate bond markets. The sample consists of non-financial, fixed-coupon corporate bonds issued in North America and the European Union since January 1, 2020, extracted from Refinitiv Eikon on April 24, 2024. After cleaning, it contains 6305 bonds, 492 of which are ESG-certified.

The premium is estimated with two approaches: a linear regression of yield to maturity on an ESG dummy and controls (coupon, days to maturity, credit grade, log amount outstanding, seniority and issue-year effects), and a nearest-neighbour matching analysis that pairs ESG bonds with similar conventional bonds of the same issuer. The paper concludes that the ESG premium is not statistically significant.

Repository layout:

├── data/Bond_data.xlsx   # Refinitiv Eikon bond-level data
├── src/script.R          # early exploratory cleaning / matching draft
├── src/script2.R         # main analysis: cleaning, regression, matching
├── dump/                 # figures produced by the scripts

## Installation
```bash
git clone https://github.com/sr-majidi/unibo-corp-esg.git
cd unibo-corp-esg
```
Install [R](https://www.r-project.org/) and the packages listed in [Requirements](#requirements), e.g. from an R session:
```r
install.packages(c("readxl", "dplyr", "tidyr", "readr", "MatchIt", "marginaleffects",
                   "car", "datawizard", "robustHD", "xtable", "fastDummies"))
```

The scripts read `Bond_data.xlsx` from the working directory, so either set the working directory to `data/` or copy the file next to the script before running it:
```bash
cp data/Bond_data.xlsx .
Rscript src/script2.R
```

## Modules

### `data/Bond_data.xlsx`
Bond-level data from Refinitiv Eikon. Columns used by the scripts include `ISIN`, `Issuer`, `Ticker`, `Sector`, `Country of Issue`, `Issue Date`, `Maturity`, `Coupon`, `Yield to Maturity`, `Amount Issued (USD)`, `Amount Outstanding (USD)`, `Principal Currency`, `Seniority`, `Bond Grade`, `Green Bond`, `ESG Bond` and `ESG Bond Type`.

### `src/script2.R`
Main analysis script.

1. **Cleaning**: parses dates and numeric columns, encodes `ESG Bond` as a 0/1 dummy, labels missing `Bond Grade` as "Not labeled", drops rows with missing yield, ESG status, amount outstanding or maturity, and drops zero amounts (a logarithm is taken later).
2. **Feature construction**: `Issue_Year`, `Days_to_Maturity` (relative to 2024-04-24) and `ln_Amount_Outstanding_USD`.
3. **Regression**: `lm(Yield_to_Maturity ~ ., data = bond_data_reg)`, leverage values via `hatvalues()` for outlier detection, and multicollinearity check via `car::vif()`. Winsorization code is present but commented out.
4. **Matching**: `MatchIt::matchit()` with nearest-neighbour matching on a GLM propensity score, exact on `Issuer` and `Bond_Grade`. Covariate balance is saved as QQ plots (`eqq_coupon.jpg`, `eqq_lnamount.jpg`, `eqq_mat.jpg`).
5. **Treatment effect**: weighted regression on the matched sample and the average effect on the treated via `marginaleffects::avg_comparisons()`.

### `src/script.R`
An earlier exploratory draft covering type conversion, missing-value handling and a first matching attempt. It is incomplete and kept for reference; use `script2.R` for the analysis.

### `dump/`
Figures generated by the scripts: matching QQ plots (`eqq_*.jpg`), the number of ESG bonds issued per year (`esg_peryear.jpg`), leverage values (`hatvals.jpg`) and a histogram/line plot (`hist_line.jpg`).

### `main.pdf`
The paper: *The ESG Premium in Corporate Bond Markets* (University of Bologna, May 17, 2024) by Ekaterina Nemchenko, Jelena Cesnokova, Sarp Derin Görgün, Shahriyar Majidi and Mohammad Kaleji.
